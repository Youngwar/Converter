# Конвертер валют ЦБ РФ

Настольное приложение на Python для конвертации валют по официальным курсам Центрального банка России. Поддерживает выбор даты курса, кэширование в SQLite и работу без интернета после первого запроса.

## Возможности

- Конвертация между любыми валютами из списка ЦБ РФ, включая рубль.
- Выбор даты курса в формате `ДД/ММ/ГГГГ`.
- Кэширование скачанных XML-файлов в локальную базу SQLite.
- Работа без интернета, если курс на выбранную дату уже загружался.
- Графический интерфейс на Tkinter.
- Обработка ошибок: отсутствие сети, повреждённый XML, неверная дата, неверная сумма.
- Учёт номинала валют (например, JPY публикуется за 100 единиц).

## Требования

- **Python** 3.8 или выше.
- **ОС**: Windows, Linux, macOS (Tkinter должен быть доступен в вашей сборке Python).
- **Интернет** — только для первого запроса курса на каждую дату.

### Зависимости

Единственная внешняя библиотека — `requests`. Всё остальное входит в стандартную библиотеку:

- `tkinter` — GUI
- `sqlite3` — кэш
- `xml.etree.ElementTree` — парсинг XML
- `unittest` — тесты
- `datetime`, `os`, `tempfile` — вспомогательные модули

## Использование

### Основной сценарий

1. В поле **«Дата курса»** введите дату в формате `ДД/ММ/ГГГГ`. По умолчанию подставлена сегодняшняя дата.
2. Нажмите **«Загрузить»** — программа скачает курс на указанную дату (или возьмёт из кэша).
3. В поле **«Сумма»** введите число. Допускается как точка, так и запятая в качестве десятичного разделителя.
4. Выберите валюты в выпадающих списках **«Из валюты»** и **«В валюту»**.
5. Нажмите **«Конвертировать»** — результат появится под кнопкой.

### Примеры

| Задача | Действие |
|--------|----------|
| Узнать курс доллара на сегодня | Дата = сегодня, Из = `RUB`, В = `USD`, Сумма = `1` |
| Перевести 1000 долларов в рубли | Из = `USD`, В = `RUB`, Сумма = `1000` |
| Посмотреть курс евро неделю назад | Дата = `ДД/ММ/ГГГГ` (неделю назад), Из = `RUB`, В = `EUR` |
| Конвертировать иены | Из = `JPY`, В = `RUB` — номинал 100 учтён автоматически |

### Формат даты

ЦБ РФ принимает дату в формате `ДД/ММ/ГГГГ`. Примеры корректного ввода:

- `27/10/2026`
- `01/01/2025`

Если дата введена неверно, программа покажет предупреждение и не выполнит запрос.

### Поведение на выходных

ЦБ РФ публикует курсы только в рабочие дни. Если запросить субботу или воскресенье, сервер вернёт курс на последний рабочий день. Это нормальное поведение, а не ошибка программы.

## Архитектура

```
┌─────────────────────────────────────────────┐
│                  GUI (Tkinter)              │
│  Поле даты │ Сумма │ Combobox │ Результат   │
└──────────────────┬──────────────────────────┘
                   │
                   ▼
┌─────────────────────────────────────────────┐
│              get_rates(date_req)            │
│  1. Проверка кэша (SQLite)                  │
│  2. Если нет — запрос к ЦБ РФ               │
│  3. Сохранение XML в кэш                    │
│  4. Возврат словаря курсов                  │
└──────────────────┬──────────────────────────┘
                   │
       ┌───────────┴───────────┐
       ▼                       ▼
┌──────────────┐       ┌──────────────────────┐
│ fetch_cbr_xml│       │   parse_cbr_xml      │
│ (requests)   │       │ (xml.etree)          │
└──────────────┘       └──────────────────────┘
```

### Поток данных

1. Пользователь нажимает «Загрузить» → вызывается `get_rates(date_req)`.
2. `get_rates` проверяет кэш по ключу `date_req` (или сегодняшней дате).
3. Если в кэше есть XML — он передаётся в `parse_cbr_xml` без обращения к сети.
4. Если в кэше нет — `fetch_cbr_xml` скачивает XML, сохраняет его в кэш и передаёт в парсер.
5. `parse_cbr_xml` возвращает словарь вида `{"USD": {"name": "Доллар США", "rate": 92.5}, ...}`.
6. GUI заполняет выпадающие списки и готов к конвертации.

### Конвертация

Любая пара валют конвертируется **через рубль**:

```
amount_in_target = amount * rate_from_to_rub / rate_to_to_rub
```

Для рубля `rate_to_rub = 1.0`, так как рубль — базовая валюта в данных ЦБ.

## Описание функций

### `init_cache_db()`

Создаёт таблицу `rate_cache` в базе `cbr_cache.db`, если её ещё нет.

```python
CREATE TABLE IF NOT EXISTS rate_cache (
    date_key TEXT PRIMARY KEY,
    xml_content BLOB NOT NULL,
    fetched_at TEXT NOT NULL
)
```

### `get_cached_xml(date_key)`

Возвращает сохранённый XML (`bytes`) для указанной даты или `None`, если записи нет.

| Параметр | Тип | Описание |
|----------|-----|----------|
| `date_key` | `str` | Дата в формате `ДД/ММ/ГГГГ` |
| **Возврат** | `bytes \| None` | XML или `None` |

### `save_xml_to_cache(date_key, xml_bytes)`

Сохраняет XML в кэш. Если запись с таким ключом уже есть — перезаписывает (`INSERT OR REPLACE`).

| Параметр | Тип | Описание |
|----------|-----|----------|
| `date_key` | `str` | Дата в формате `ДД/ММ/ГГГГ` |
| `xml_bytes` | `bytes` | Содержимое XML-файла |

### `parse_cbr_xml(xml_bytes)`

Парсит XML ЦБ РФ и возвращает словарь курсов.

| Параметр | Тип | Описание |
|----------|-----|----------|
| `xml_bytes` | `bytes` | XML в кодировке windows-1251 |
| **Возврат** | `dict` | `{код: {"name": str, "rate": float}}` |

Особенности:

- Заменяет запятую на точку в поле `Value`.
- Делит значение на `Nominal`, чтобы получить курс за 1 единицу валюты.
- Может выбросить `xml.etree.ElementTree.ParseError` при повреждённом XML.

### `fetch_cbr_xml(date_req=None)`

Скачивает XML с сайта ЦБ РФ.

| Параметр | Тип | Описание |
|----------|-----|----------|
| `date_req` | `str \| None` | Дата `ДД/ММ/ГГГГ` или `None` (последняя дата) |
| **Возврат** | `tuple[bytes, str \| None]` | XML и дата из атрибута `Date` |
| **Исключения** | `RuntimeError` | При ошибке сети |

### `get_rates(date_req=None)`

Основная функция получения курсов. Объединяет кэш и сеть.

| Параметр | Тип | Описание |
|----------|-----|----------|
| `date_req` | `str \| None` | Дата или `None` (сегодня) |
| **Возврат** | `tuple[dict, str]` | Словарь курсов и фактическая дата |
| **Исключения** | `RuntimeError` | Если сети нет и кэша тоже нет |

Логика:

1. Если `date_req` указан и в кэше есть XML — вернуть из кэша.
2. Иначе попытаться скачать.
3. При успехе — сохранить в кэш и вернуть.
4. При ошибке сети — если есть кэш, вернуть его; иначе выбросить `RuntimeError`.

## Кэширование

### Где хранится

Файл `cbr_cache.db` в папке со скриптом. Это обычная база SQLite, её можно открыть любым SQLite-клиентом.

### Схема

| Поле | Тип | Описание |
|------|-----|----------|
| `date_key` | `TEXT PRIMARY KEY` | Дата `ДД/ММ/ГГГГ` |
| `xml_content` | `BLOB` | Сырой XML от ЦБ РФ |
| `fetched_at` | `TEXT` | Когда скачано (ISO 8601) |

### Правила работы

- Для **конкретной даты** кэш — основной источник. Если запись есть, сеть не используется.
- Для **сегодняшней даты** (когда `date_req=None`) программа сначала пытается скачать свежие данные. Если сеть недоступна — падает обратно на кэш за сегодня.
- Кэш не имеет срока давности: если курс на дату уже сохранён, он не будет перезаписан при повторном запросе той же даты.

### Очистка кэша

Удалите файл `cbr_cache.db` — при следующем запуске он создастся заново.

Или через SQLite:

```sql
DELETE FROM rate_cache;
```

## Тестирование

Тесты находятся в файле `test_cbr.py`. Они **не обращаются к сети**: используется образец XML и временная база данных.

### Запуск

```bash
python test_cbr.py
```

Или через `unittest`:

```bash
python -m unittest test_cbr -v
```

### Что покрыто

**Парсер XML:**

- Возврат словаря.
- Корректный курс USD и EUR.
- Деление на номинал для JPY (100 иен → курс за 1 иену).
- Наличие всех валют из образца.
- Замена запятой на точку.
- Исключение `ParseError` при повреждённом XML.

**Кэш SQLite:**

- Сохранение и чтение XML.
- `None` для отсутствующей записи.
- Перезапись существующей записи.

### Добавление тестов

Если нужно проверить сценарий «сеть упала, но кэш есть», можно замокать `requests.get` через `unittest.mock.patch`:

```python
from unittest.mock import patch

@patch("cbr_converter_pro.requests.get")
def test_fallback_to_cache(self, mock_get):
    mock_get.side_effect = requests.RequestException("no network")
    # ... предварительно сохранить XML в кэш ...
    rates, _ = get_rates("27/10/2026")
    self.assertIn("USD", rates)
```

## Сборка в .exe

Для распространения программы пользователям без Python используйте PyInstaller.

### Установка

```bash
pip install pyinstaller
```

### Сборка

```bash
pyinstaller --onefile --windowed cbr_converter_pro.py
```

- `--onefile` — один `.exe`.
- `--windowed` — без консольного окна.

Готовый файл появится в `dist/cbr_converter_pro.exe`.

### Важно

- База `cbr_cache.db` создаётся **рядом с исполняемым файлом** при первом запуске. Убедитесь, что у пользователя есть права на запись в эту папку.
- Если хотите, чтобы кэш хранился в профиле пользователя, замените путь `CACHE_DB` на что-то вроде `os.path.join(os.path.expanduser("~"), ".cbr_converter", "cache.db")`.

## Возможные проблемы

### «Не удалось получить данные с сайта ЦБ РФ»

- Проверьте интернет.
- Сайт ЦБ РФ может быть временно недоступен — попробуйте позже.
- Если курс на эту дату уже был загружен ранее, программа должна взять его из кэша. Если этого не произошло — проверьте, существует ли файл `cbr_cache.db` рядом со скриптом.

### «Введите дату в формате ДД/ММ/ГГГГ»

- Убедитесь, что используется прямой слэш `/`, а не обратный `\`.
- День и месяц — двузначные (`01`, а не `1`).

### «Валюта не найдена»

- Обычно означает, что данные не загружены. Нажмите «Загрузить» и повторите конвертацию.

### «Кракозябры» в названиях валют

- Возникает, если XML был прочитан как `response.text` вместо `response.content`. В текущей версии используется `response.content` и `ET.fromstring(bytes)`, поэтому проблема не должна появляться.

### Tkinter не найден (Linux)

В некоторых дистрибутивах Tkinter ставится отдельно:

```bash
sudo apt install python3-tk      # Debian/Ubuntu
sudo dnf install python3-tkinter # Fedora
```

### Кэш не работает после сборки в .exe

- Убедитесь, что `CACHE_DB` указывает на путь, доступный для записи. Внутри `.exe` путь `sys._MEIPASS` — временный и только для чтения.
